SUMMARY

This document outlines the optimal prototype build path for Accountabuild—a fitness-focused social accountability app—for the iPhone (with a React Native codebase ready for Android expansion). It covers:

• A high-level overview of the Minimum Viable Product (MVP) features and objectives
• The recommended technology stack (frontend, backend, database, and supporting services)
• Development environment setup steps
• Detailed backend and frontend implementation phases
• Third-party integrations (HealthKit, real-time chat, push notifications, media storage)
• Infrastructure and deployment considerations
• Testing and quality assurance strategies
• A granular micro-level checklist for tracking completion of each task

ACCOUNTABUILD PROTOTYPE BUILD PATH

1. MVP DEFINITION
   a. Core features:
      - User authentication (sign-up, login, password reset)
      - Profile management (username, avatar)
      - Group management (create, join, leave groups)
      - Chat per group (real-time messaging)
      - Goal tracking (e.g., 5 workouts/week)
      - HealthKit integration (read workout data)
      - Photo upload (selfies, gym pics)
      - Notifications (push reminders, goal updates)

2. TECHNOLOGY STACK
   • Frontend: React Native (iOS initially, Android later)
   • Backend: Node.js + Express (or NestJS) REST API
   • Database: PostgreSQL
   • ORM: Prisma or TypeORM
   • Storage: AWS S3 for images
   • Authentication: JWT or Auth0
   • Real-time: Socket.io or AWS AppSync
   • Push notifications: Firebase Cloud Messaging (FCM) + APNs
   • Dev tools: TypeScript, ESLint, Prettier, Jest

3. DEVELOPMENT ENVIRONMENT SETUP
   1. Install Node.js (LTS) and Yarn/npm
   2. Install Xcode and CocoaPods
   3. Install Android Studio (for future Android)
   4. Install Docker and Docker Compose (for Postgres)
   5. Configure AWS CLI and IAM credentials

4. BACKEND DEVELOPMENT
   4.1. Scaffold API
      - `npx express-generator --no-view --typescript accountabuild-api`
      - Configure ESLint, Prettier, Husky
   4.2. Database
      - Create `docker-compose.yml` with Postgres service
      - Define Prisma schema:
         • User model
         • Group model
         • Membership model
         • Message model
         • Goal model
         • Workout record model
      - Run `docker-compose up` and `npx prisma migrate dev`
   4.3. Authentication & Authorization
      - Implement `/auth/register` and `/auth/login` endpoints
      - Use bcrypt for passwords, JWT for sessions
      - Middleware to protect routes
   4.4. Group & Chat APIs
      - CRUD for groups
      - Membership endpoints (join, leave)
      - Message endpoints (send, fetch history)
      - Real-time messaging with Socket.io setup
   4.5. Goal & Workout Tracking
      - Define goal endpoints (create, update, delete, fetch)
      - Workout record endpoints (sync from HealthKit)
   4.6. Photo Upload
      - Configure AWS S3 bucket
      - Implement signed-URL endpoint for uploads
      - Store image URLs in database
   4.7. Notifications
      - Integrate FCM for Android and APNs for iOS
      - Implement push notification service

5. FRONTEND DEVELOPMENT (React Native)
   5.1. Project Initialization
      - `npx react-native init Accountabuild --template react-native-template-typescript`
      - Install navigation (`@react-navigation/native`), UI library
   5.2. Directory Structure
      /src
         /api  — API service clients
         /components  — reusable UI elements
         /screens  — Login, Register, Home, Group, Chat, Profile, Settings
         /store or /hooks  — state management (Context, Redux, or Recoil)
         /utils  — helpers, constants
   5.3. Authentication Flow
      - Screens: LoginScreen, RegisterScreen, ForgotPasswordScreen
      - Store JWT token securely (AsyncStorage + encrypted storage)
      - Redirect to Home after login
   5.4. Group & Chat UI
      - GroupListScreen (list of joined groups)
      - CreateGroupScreen (form)
      - GroupDetailScreen (info, members)
      - ChatScreen (message list, input bar, real-time updates)
   5.5. Goal Tracking UI
      - GoalOverviewScreen (current goals, progress bars)
      - WorkoutSyncService (HealthKit wrapper for iOS)
   5.6. Photo Upload UI
      - Camera roll access, image picker
      - Upload progress indicator
   5.7. Notifications & Permissions
      - Request permissions for notifications and HealthKit
      - Handle incoming notifications in app

6. INTEGRATIONS
   6.1. Apple HealthKit
      - Use `react-native-health` or `@whitelab/react-native-healthkit`
      - Request `workout` and `activitySummary` permissions
      - Periodic sync of workouts to backend
   6.2. Push Services
      - iOS: APNs via `@react-native-community/push-notification-ios`
      - Android (later): FCM via `@react-native-firebase/messaging`
   6.3. Real-time Chat
      - Socket.io client in React Native
      - Configure channels per group

7. INFRASTRUCTURE & DEPLOYMENT
   • Version control: GitFlow or trunk-based
   • CI/CD: GitHub Actions or CircleCI
      - Lint, test, build, deploy
   • Backend hosting: AWS ECS / Fargate or Heroku
   • Database hosting: AWS RDS for Postgres
   • Storage: AWS S3
   • Environment management: `.env` files + secrets store
   • Monitoring: Sentry for errors, AWS CloudWatch

8. TESTING & QA
   8.1. Backend tests (Jest + Supertest)
      - Unit tests for controllers, services
      - Integration tests for API endpoints
   8.2. Frontend tests (Jest + React Native Testing Library)
      - Component snapshots
      - Screen behavior tests
   8.3. Manual QA
      - iOS TestFlight distribution
      - Test user flows: signup, create group, chat, sync
